# Repository templates

These files are staging templates for repositories that the current GitHub connection cannot create directly.

- `profile/README.md` is intended for a future public `mixu-94/mixu-94` profile repository.
- `next-starter/` is intended for a future public `mixu-94/next-starter` template repository.

Keeping the source templates here means they can be reviewed and versioned alongside the reusable workflows before being copied into their final repositories.
