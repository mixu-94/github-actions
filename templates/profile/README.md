## Featured tooling

### [github-actions](https://github.com/mixu-94/github-actions)

Reusable workflows and small in-house actions for CI, security checks, releases, dependency updates, and pull-request automation.

The goal is simple: keep project repositories small while centralizing the repetitive infrastructure in one place.

## Selected work

I'm currently refreshing several application projects as portfolio/reference projects. Their focus is not just the UI, but also showing how I structure CI, releases, testing, dependency maintenance, and repository security.

## How I like to build

- automate repetitive work, but keep automation understandable
- validate before merging or releasing
- keep permissions and secrets as narrow as possible
- prefer reproducible builds over "works on my machine"
- keep major dependency upgrades deliberate instead of blindly automatic
